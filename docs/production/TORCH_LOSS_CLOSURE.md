Scope: CrossEntropyLoss, BCEWithLogitsLoss, MSELoss, L1Loss, NLLLoss, KLDivLoss, CTCLoss and TripletMarginLoss. ## Shared objective and target boundary

Losses are training-control components with one typed `objectiveRecipe` output, wired to Train's optional single `objective` input. They are not model-forward adapters. Only the source-qualified connected recipe takes effect; disconnected components do not change the run. Default recipe selection never silently rewrites a saved graph. Configuration version and canonical recipe schema begin at 1. Canonical recipe has exactly schemaVersion/componentID/configurationVersion/config; the workflow wrapper adds the actual qualified source address and target mapping. Its identity is pinned in preparation, execution, capture, checkpoint, History and export. A standalone call may provide canonical configuration without inventing a canvas address.

Prediction tensors are observation-first float32. Batch size is runtime-controlled and includes short final batches. Full tensor rank is bounded to 2–8, sample directions to 1–4096, class count to 2–512; input, output, target, broadcast and intermediate allocations are independently bounded to 100,000,000 elements. CTC alignment work is additionally bounded before allocation by the configured batch/time/active-target geometry. Checked arithmetic must refuse overflow. Targets use float32 or exact int64 according to the declared role; booleans, fractional integers, nonfinite numbers and unknown keys are refused. CPU and MPS are actual tested device cases; a device refusal must be specific and actionable, never an undeclared CPU transfer. Existing native CTC tiny forward/backward probes succeeded on both installed Torch 2.14.1 devices; that probe is not full integration acceptance.

`LossTargetMapping` has distinct validated variants, not a permissive dictionary:

- **Ordinary target:** ordered row-major source columns, explicit sample shape and dtype. The scalar sample is shape `[]`, distinct from `[1]`. CE class-index and NLL targets are int64; other ordinary targets are float32. Column count equals the shape's element count. Source column spelling is user-authored and preserved.
- **CTC sequence:** fixed ordered padded target columns of sample shape `[Smax]`, one exact int64 input-length column and one exact int64 target-length column per observation. Target length may be zero and cannot exceed Smax; input length is 1…T. `target_layout=padded` passes `[N,Smax]`; `packed` concatenates each current batch row's active prefix into `[sum(target_lengths)]`. Neither reads ignored suffixes nor concatenates the whole dataset independently of batching. Active labels are in 0…C−1 and cannot equal blank. Repeat labels and alignment feasibility are checked; infeasibility remains visible when zero_infinity masks it.
- **Model triplet:** output `[N,3,D]` with explicit ordered sample roles anchor/positive/negative at positions 0/1/2. Ordered source feature groups have equal width and are packed in that same order. A shared learned model processes the three sample positions; no separate-model engine or dummy target column is introduced. This mapping is a meaningful source/role binding even though class labels are absent. Misordered roles, unequal feature groups and any output middle dimension other than 3 refuse.

Optional named `weight` and `pos_weight` target roles are float32 with independently declared sample geometry. They are available only when that recipe selects mapped weights. Prepared partitions retain exactly the same rows, source-column identities and split provenance across predictions, targets, lengths and weights. The current table binding retains TrainingColumnMapping.maximumColumns=128 for ordered input columns and each role; this is distinct from native tensor direction limits of 4096 and configuration-vector limits. No change silently relaxes that table boundary. Validation rows never fit data transforms. Requested roles must exist and unexpected roles refuse. Preparation cache identity includes mapping and recipe; changing either invalidates affected prepared evidence.

Class directions use full observation-first tensor axis indices, excluding batch axis 0. `class_axis=-1` defaults to the final direction; support −7…7 with 0 refused and actual-rank normalization that also refuses any negative alias of the batch direction. CE/NLL move that direction to native dimension 1 immediately before the objective, retaining public observation-first previews and target geometry. No implicit softmax/log-softmax, reshape, label encoding or target normalization repairs malformed data. NLL, KL and CTC require finite log-probability inputs; their contract and lesson explain that LogSoftmax produces them. Validate distribution normalization within a documented float32 tolerance of 1e−4, and refuse malformed distributions with a remedy. Probability targets are finite 0…1 distributions along the class direction, with the same tolerance. Zero probability is admitted where native semantics define its zero contribution; an infinite logarithm is outside this finite-input boundary.

## Frozen IDs and configurable members

Shared reductions are `none`, `mean`, `sum`, default `mean`; KL additionally supports `batchmean`. Deprecated size_average/reduce aliases are excluded because they duplicate reduction, rather than counted as extra controls. All floats must be finite and float32-representable. Positive bounds use Float32's least positive subnormal (1.401298464324817e−45); maximum is 3.4028234663852886e38 unless a tighter bound follows. Configurations are strict typed values and do not accept booleans as numbers.

| Component ID / PyTorch member | Exact controls and defaults | Required substantive nondefault cases |
| --- | --- | --- |
| `loss_cross_entropy` / CrossEntropyLoss | reduction mean; target_mode `class_indices` or `probabilities` (default indices); class_axis −1; class_weights `[]` means absent, otherwise C finite nonnegative weights; ignore_index −100 (signed int32); label_smoothing 0…1 default 0 | weighted index targets, ignored rows, spatial/sequence class axis, smoothing including 1, weighted probability targets, sum/none and short final batch |
| `loss_bce_with_logits` / BCEWithLogitsLoss | reduction mean; weight_mode and pos_weight_mode each `none/configured/mapped` default none; each has explicit shape `[]` and values `[]` defaults, dormant when unused | multilabel outputs, positive and element weights separately/together, configured scalar/per-class/grid broadcasts, genuinely mapped per-observation weights, soft 0…1 targets, zero weights, sum/none |
| `loss_mse` / MSELoss | reduction mean; target_broadcast false | exact multidirection target, explicitly admitted sample-only broadcasting, sum/none, negative and zero values |
| `loss_l1` / L1Loss | reduction mean; target_broadcast false | same mapping diversity; positive/negative errors, exact zero-error subgradient, sum/none |
| `loss_nll` / NLLLoss | reduction mean; class_axis −1; class_weights `[]` absent; ignore_index −100 signed int32 | actual LogSoftmax source, weighted/ignored/spatial targets, sum/none, different class-axis layout |
| `loss_kl_div` / KLDivLoss | reduction mean; log_target false | probability and logarithmic targets, zero probability, none/sum/mean/batchmean with visibly different denominators, unequal distributions |
| `loss_ctc` / CTCLoss | reduction mean; blank 0 integer 0…511 validated against actual C; zero_infinity false; target_layout `padded/packed` default padded | repeated labels, variable input/target lengths, empty active target, nonzero blank, both target layouts, impossible alignment with both zero_infinity choices, sum/none |
| `loss_triplet_margin` / TripletMarginLoss | reduction mean; margin positive default 1; p positive…16 default 2; eps nonnegative default 1e−6; swap false | positive real p including 0.5/1/1.5, different positive margins, eps 0/nondefault, active/inactive margin, swap changes closest negative, all three input gradients, sum/none |

Class weights have at most 512 entries and must match C; all-zero effective weights are permitted only when the chosen reduction has a defined finite result. Mean with no active effective denominator refuses with a clear message, including all-ignored index targets. CE probability targets do not acquire ignore-row semantics: configure ignore_index −100, and refuse other values in that target mode rather than silently ignore the setting. Label smoothing follows native weighted numerator/denominator semantics; do not substitute a uniform average implementation.

Configured BCE weights are **observation-independent sample tensors**: shape has at most 7 positive dimensions, values have 1…4096 entries and exactly match declared shape (shape `[]` is one scalar). Explicit sample broadcasting aligns trailing sample directions; a leading batch-shaped configured constant is forbidden. Mapped weights prepend the current N and preserve per-row ownership. Both weight families may be scalars or valid native broadcasts; materialized broadcast cannot exceed resource bounds. Values are nonnegative, including zero; native weighting and positive-term weighting are distinct. Dormant shape/value settings remain editable/persisted but never grant a missing mapped role.

MSE/L1 targets must exactly match predictions by default. With target_broadcast true, only sample axes broadcast; prepend the same observation N and align sample axes explicitly. Refuse accidental `[N]` versus `[N,1]` outer-batch expansion. The emitted helper performs the same explicit operation.

CTC prediction layout is `[N,T,C]`, transposed to `[T,N,C]` only for the native call. Mean is the mean of each observation's loss divided by its target length under installed native semantics (including the actual empty-target convention), not total loss divided by all labels. CTC none yields `[N]`. Native nonfinite objective/gradient fails with alignment diagnostics unless zero_infinity explicitly masks impossible alignments; show masked observation counts and do not report them as successful matches.

The installed native Triplet constructor/backward was directly probed with p=0.5/1/1.5/2/16. Positive real p is genuine; p≤0 and p>16 are the declared consumer exclusions. Small p can have sharp behavior near zero distance, which must be diagnosed if results become nonfinite. eps is added in the native distance calculation, not an invented denominator floor. Ties/cusps and swap behavior retain documented native subgradients.

## Reduction, evaluation and inference

Train adds explicit `objective_scalarization=mean/sum`, default mean, **used only after recipe reduction=none**. Raw none-reduction arrays remain available in Results and export. The actual optimization scalar is recorded separately; no detached value, hidden mean or automatic gradient argument may replace it. Other reductions retain native values, including KL's batchmean denominator and CTC's per-target-length mean. Batch/epoch aggregation records sufficient numerator/denominator metadata to avoid averaging unequal final batches incorrectly. Masked/ignored observations remain labeled.

Evaluation uses the same pinned configuration on held-out targets. Universal evidence is objective output/raw geometry/effective scalar/active counts, not accuracy. Optional classification metrics explicitly declare their decoding rule, threshold/class direction and eligibility. Regression error, sequence alignment and triplet separation have their own labeled readouts. Existing Plateau validation_loss consumes the declared effective validation scalar; validation_accuracy refuses before running when the selected objective/task supplies no defined classification accuracy. General inference exports preserve actual model output shape and dtype; classification decoding is a declared optional task adapter, never unconditional argmax for these eight.
