Readers are bounded and restartable, not arbitrary user callbacks or unbounded generators. Worker count is 0–2; source/worker/prefetch admission remains bounded. Exact continuation is epoch-boundary CPU, not mid-batch continuation. Program export is a configured History artifact action, never a forward-function node. Evaluation mode, one ordinary float32/int64 tensor input and tensor output, fixed sample axes, static or bounded leading batch are the reviewed contract. Bag packets refuse. Exported programs are executable trusted local artifacts; hashes and framing do not make untrusted loading safe. Existing managed-operation supervision provides timeout/cancellation and joined terminal ownership; no tracing callback is represented as interruptible supervision.
